# 面向高中生的 Vibe Coding

## 你不必害怕编程

Vibe Coding 是一种用自然语言描述目标、让 AI 协助生成小段代码、运行结果、阅读错误并持续改进的工作方式。它降低了开始编程的门槛，但不会替你做产品判断。

## 一个好的循环

```text
描述一个小目标 → 生成代码 → 运行 → 观察 → 提问为什么 → 修改 → 测试
```

一次只改变一个小行为。让 AI 说明修改了什么、为什么这样修改、可能失败在哪里，并要求它提供可检查的测试。

## 保持创造力和责任

学生仍然是产品负责人、设计师、研究员、测试者和决策者。AI 不是来源，也不能决定哪些信息真实。任何机会的名称、费用、资格、截止日期和结果都必须回到官方资料核验。

## 常见错误

- 一次要求 AI 建造整个应用。
- 复制代码却不运行、不阅读。
- 把看似合理的 AI 输出当成事实。
- 没有保存小步提交，导致无法回退。
- 只关注界面而忽略数据、隐私和错误状态。

## 最佳实践

从一个可演示的小功能开始，保留问题和解决方案记录，提交可理解的版本，邀请同伴测试，并把学到的概念写回项目文档。
