# Moteur d’équité des opportunités — Guide de projet pour débutants

## Bienvenue

Il n’est pas nécessaire d’être programmeur avant de commencer. Le projet combine réflexion produit, recherche, design, tests et petites étapes de développement. L’IA peut expliquer du code et proposer un point de départ, mais l’élève reste responsable des décisions, des données et de la qualité.

## Comprendre le problème

Interrogez des élèves, parents ou enseignants. Notez comment ils cherchent des possibilités, ce qu’ils manquent et quelles informations influencent leur décision. Transformez ces observations en un problème précis avant d’ajouter des fonctionnalités.

## Parcours d’apprentissage

1. Découvrir GitHub et les outils de développement du navigateur.
2. Comprendre la structure de base de HTML, CSS et JavaScript.
3. Représenter une opportunité en JSON.
4. Apprendre les conditions, tableaux, fonctions et formulaires.
5. Filtrer et classer avec des règles déterministes.
6. Tester les comportements importants et observer de vrais utilisateurs.

## Première tranche verticale

```text
Profil → Données d’exemple → Admissibilité → Résultats → Explication
```

Commencez avec quelques fiches vérifiées, un formulaire, une page de résultats et une page de détail. Ajoutez ensuite les sauvegardes, la recherche, la revue administrative et les notifications.

## Utiliser l’IA avec prudence

Donnez à l’IA une petite tâche, une entrée, une sortie et des critères d’acceptation précis. Demandez-lui d’expliquer ses changements et fournissez des tests. Toute date, exigence, coût ou règle doit être vérifié auprès d’une source officielle.

## Définition de terminé

L’élève peut terminer le parcours, comprendre le résultat, consulter la source officielle et choisir une prochaine action. Le code fonctionne, les états d’erreur sont prévus, les données ont une source et l’équipe peut expliquer ses décisions.
