# 机会公平引擎——预计项目时间线

## 规划假设

时间线按一个学期、每周有固定协作时间、以演示型 MVP 为目标来安排。它可以因团队规模、学校日程和用户反馈调整。

## 阶段

1. **第 1–2 周：理解问题**——采访用户，确认范围，记录假设和成功指标。
2. **第 3–4 周：设计体验**——绘制流程、制作低保真和可点击原型。
3. **第 5–6 周：准备数据**——定义机会模式，收集少量官方来源并核验。
4. **第 7–9 周：实现垂直切片**——完成档案、资格判断、匹配结果和解释。
5. **第 10–11 周：补充管理能力**——加入保存、详情页、搜索和审核队列。
6. **第 12–13 周：测试与改进**——进行流程、可访问性和用户测试，修复阻塞问题。
7. **第 14–16 周：准备交付**——部署演示，整理文档、展示脚本、限制和下一步。

## 每周节奏

每周开始时选择少量目标，中途同步阻塞项，结束时演示可运行成果并记录决定。没有完成的功能要重新排序，而不是无限增加范围。

## 里程碑

最重要的里程碑是：问题陈述、原型、已核验样例数据、第一次端到端流程、用户测试反馈和可重复演示。每个里程碑都应有明确的验收标准。
