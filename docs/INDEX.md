## Documentation standards

- Keep one primary purpose per document.
- Keep related documents together in the same numbered topic folder.
- Use clear, descriptive filenames.
- Link from this index when adding a new document.
- Preserve source URLs and verification dates in opportunity-related content.
- Label mockups, sample data, and future ideas clearly.
- Keep beginner instructions concrete and explain unfamiliar terms.
- Update the root README when the project scope or starting path changes.

## Current project status

The repository currently contains the initiative charter, bilingual product plans, architecture, student guides, delivery plan, research materials, the 600-source opportunity catalog, implementation guide, toolkit, and visual demo deliverables. The next practical milestone is the vertical-slice application described in [DEMO_IMPLEMENTATION_GUIDE.md](05-build/DEMO_IMPLEMENTATION_GUIDE.html).
