# 机会股权引擎 — 600 个来源机会目录

**编译对象：** 11 年级/中学机会发现
**主要地理位置：** 蒙特利尔/魁北克 → 加拿大范围 → 加拿大学生可获得或相关的精选国际机会
**编译日期：** 2026-09-09
**总记录：** 600（每个类别 100 条）

## 如何使用该文件

这是**机会股权引擎的源目录**，并非声称所有 600 个申请当前均处于开放状态。

年度项目经常关闭和重新开放。已关闭的 2026 年页面仍然可以成为 2027 年周期的有效经常性来源。在向用户展示机会之前，应用程序应重新检查官方来源以了解当前资格、日期、费用、地点和申请状态。

### 验证层

- **A — 实时检查的直接来源：** 在本次研究过程中检查了特定页面或当前周期来源。
- **B — 官方来源/机构中心：** 官方大学、政府、非营利组织、医院或组织者来源。必须重新检查确切的年度活动或申请周期。
- **C — 发现来源：** 信誉良好的目录、聚合器或广泛来源。在系统解析并验证官方组织者页面之前，**不要**将其视为权威。

### 推荐的摄取字段

`category`、`opportunity_name`、`organization`、`geography`、`audience`、`source_url`、`verification_tier`、`reference_event`、`last_verified`、`deadline`、`status`、`cost`、`eligibility_rules`、`official_source_url`。

1. **永远不要从头衔推断资格。** 解析并存储明确的年级、年龄、居住地、公民身份、语言、学术、财务和地点限制。
2. **比起聚合器，更喜欢官方组织者页面。** 发现网站对于寻找机会很有用，但截止日期和资格字段必须与官方来源保持一致。
3. **将特定周期的日期与重复项目标识分开存储。** 示例：“项目 = 麦吉尔开放日”； `周期= 2026`; `事件日期 = 2026-10-24`。
4. **除非官方当前周期消息来源确认，否则请勿将计划标记为“开放”。**
5. **单独记录成本和助学金的可用性。** 具有大量基于需求的援助的付费项目不应被视为与无援助的付费项目相同。
6. **区分直接 11 年级资格和未来衔接参考。** 本目录中的一些研究来源主要服务于 CEGEP/本科生，并作为衔接/参考来源，而不是直接 11 年级申请。
7. **对于健康、身份、移民、残疾和财务需求资格，尽量减少敏感数据收集。** 优先选择用户控制的过滤器和明确同意。
8. **添加自动“last_verified”时间戳和过时数据策略。** 高价值记录应在活跃应用季节期间至少每 30-60 天重新验证一次。
9. **保留与魁北克相关的双语源文本。** 翻译合格语言时不得改变其法律或行政含义。
10. **只有在严格的资格门槛之后才按适合度排名。** 如果学生未达到强制性年龄、年级、居住地或公民身份规则，则 95% 的语义匹配是无关紧要的。

## 重要限制

这是一个**研究种子数据集**，不是法律或行政上的权威数据库。计划名称、可用性、资格规则和 URL 可能会更改。 A 级参赛作品在此阶段获得了最强的直接验证； B 级和 C 级记录应在作为当前机会呈现之前由应用程序刷新。
