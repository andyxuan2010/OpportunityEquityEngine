# 机会公平引擎——高层架构

## 系统概览

系统由学生体验、机会目录、匹配引擎、搜索、管理员审核和基础设施组成。第一版可以使用简单的 Web 应用和托管数据库，保持组件边界清晰，便于学生逐步学习。

## 核心流程

```text
档案 → 结构化机会记录 → 资格规则 → 匹配分数 → 解释 → 学生行动
```

来源资料先经过 AI 辅助提取，再由验证规则和人工审核确认。只有审核通过的记录才进入推荐结果。

## 主要数据

- 学生档案：年级、地区、兴趣、语言、预算和时间安排。
- 机会记录：名称、类别、组织、地点、费用、截止日期和资格条件。
- 来源证据：官方 URL、摘录、核验日期、状态和审核人。
- 用户行为：保存、忽略、提醒和完成的下一步。

## 匹配与搜索

硬性条件，例如年级、地区和截止日期，使用确定性规则处理。软性因素，例如兴趣，可以参与透明的排序。每个分数都应能拆解为符合条件、兴趣相关性、成本、时间和截止日期等原因。

搜索支持关键词和结构化筛选。系统不能把语义相似误当成资格条件；官方来源仍是最终依据。

## 安全与隐私

只收集匹配所需的数据，避免不必要的敏感个人信息。生产环境应使用身份验证、最小权限、秘密管理、日志审计、输入验证和备份。管理员操作需要可追踪。

## 运行与演进

监控应关注数据新鲜度、抓取或导入失败、搜索错误、审核队列和应用可用性。先交付一个可测试的垂直切片，再逐步加入通知、更多数据源、向量搜索和规模化部署。
