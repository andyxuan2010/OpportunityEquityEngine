## Normes documentaires

Chaque document doit avoir un objectif clair. Les nouveaux contenus doivent rester dans le dossier thématique approprié et être ajoutés à cet index. Les informations sur les opportunités doivent conserver leur URL source et leur date de vérification, et distinguer les données d’exemple des idées futures.
