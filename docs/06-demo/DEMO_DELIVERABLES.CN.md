# 机会公平引擎——演示交付物

## 目的

演示应让观众看到一个学生如何从不确定开始，找到适合自己的机会，理解推荐理由，并采取一个明确的下一步。

## 推荐用户流程

1. 学生填写年级、地区、兴趣、语言、预算和可用时间。
2. 系统显示带有匹配分数、截止日期、费用和解释的推荐。
3. 学生使用分类、地点、费用和截止日期进行搜索和筛选。
4. 详情页展示资格条件、来源证据、核验状态和官方申请链接。
5. 学生保存机会并整理截止日期。
6. 管理员在审核队列中确认或修正记录。

## 视觉素材

仓库中的演示截图包括学生引导、仪表板、机会详情、搜索、保存截止日期、管理员审核、移动端匹配和影响结果。素材是产品方向和展示辅助，不代表已经上线的功能。

## 展示脚本

先说明机会信息分散的问题，再用一个具体学生档案演示从匹配到行动的完整流程。随后展示来源证据和管理员审核，说明系统如何避免把 AI 猜测当成事实。

## 成功标准

观众可以说出学生为什么看到这个机会、信息来自哪里、下一步是什么，以及哪些部分仍属于样例或未来计划。演示必须诚实表达限制，不承诺录取结果。
